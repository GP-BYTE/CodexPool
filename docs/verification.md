## 脱敏范围

这是单独的源码导出目录。保留程序、合成测试、Go 依赖声明、必要协议证据，以及重新整理的公开文档。原本机目录中的个人使用说明、内部研究与验收记录未作为公开文档复制。

个人主目录测试路径已替换成虚构路径；协议说明中的个人账号操作记录已移除。Git 作者与提交者使用中性的项目贡献者名称与保留示例域邮箱。源码包不包含原 Git 历史、账号目录、认证文件、缓存、日志、恢复数据、开发二进制、编辑器或系统元数据。

`scripts/check_public_export.py` 检查常见 token、JWT、私钥、真实邮箱、个人主目录路径、认证数据文件和符号链接。脚本只报告位置与规则名称，不回显匹配内容。额外进行导出内容与已知私人身份的本地比对，不把私人身份写入公开规则。

这些检查降低误发布风险，不能证明任意未来提交都没有隐私内容。构建产物与图片应另行审查；本次发布只分发已检查的源码。

## 验证边界

本次没有登录真实账号、查询真实额度、运行真实模型任务或修改 Desktop 认证状态。现有合成测试和本地构建不代表其他 Codex 版本、Linux/Windows 实机或真实多账号行为已经验证。GitHub CI 配置面向 macOS 与 Ubuntu；远端执行结果以 Actions 页面为准。

首次远端 Ubuntu 检查发现 Desktop helper 的测试假定所有平台都返回 macOS 参数错误码；已修正为非 macOS 断言“不支持平台”退出码，保留平台拒绝行为。原始发布的 macOS CI 已通过，修复候选通过本地 helper race 回归；更新后的双平台结果见 Actions。
